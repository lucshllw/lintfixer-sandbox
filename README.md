# lintfixer-sandbox

Repositorio sandbox real criado para validar o **LintFixer**:
- Pesquisa & exploracao de repositorios e commits via GitHub
- Filtro barato pre-LLM (ignora lockfiles e arquivos fora de escopo)
- Git Score (0-100) + Lint Semantico com evidencia literal
- Auto-Fix verificavel sem tocar em testes ou configs
- Hooks locais de commit e PR Bot via GitHub Actions (zero chaves no repo)
